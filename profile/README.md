MRUHacks is Mount Royal University's largest hackathon and one of Calgary's
biggest student coding events. It's a free, in-person, three-day event at the
Riddell Library and Learning Centre. Designers, developers, and anyone curious
about tech come from schools across Alberta to build something over the weekend,
and every skill level is welcome. See what past hackers have built on the
[project gallery](https://mruhacks.ca/projects).

## 🛠️ What we build

The organizing team also writes the software that runs the event. Everything
here is open source.
